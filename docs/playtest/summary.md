# Playtest — 13 campaign runs, seed 1

Generated by `tools/Faultline.Playtest`. Every run played the same campaign at the
same seed, so the boards, the enemy plans and every draw were identical. The only
thing that differed is how the players chose — anything below is caused by play.

**`--seed` is inert for the deterministic policies, and re-running at another seed is
not a second sample.** Nothing in `Faultline.Core` constructs or consumes an `IRng` on
this campaign, so `first-legal`, `brawler`, `shover`, `careful`, `board-first`,
`blade-first` and `preserver` produce byte-identical logs at every seed — verified by
diffing seeds 1 and 2, which differ only in the log's own `seed` line. The `random-*`
rows are seeded from `policy.Name.GetHashCode()`, which .NET randomises per process,
so they do not repeat between runs either and are not comparable across baselines.

Every number here is `CampaignLibrary.Faultline`, the linear ten. The harness cannot
walk a mapped run (D-125).

## Preen against what it soaked

The negative-sum check. Preen is a flat 4 heal — it is not scaled to anything —
and the only thing that fills a Wardbearer's meter is absorbing hits meant for somebody
else, so what he heals should not exceed what the stance took for the squad.

**Absorbed is the blow the ally was spared, before the guard's own halving.** He pays
`Guard.Halve` of it; the squad is spared all of it. Counting what he paid instead
understates every absorb by half.

|---|---|---|---|
| `first-legal` | 0 | 0 | 0 |
| `brawler` | 0 | 0 | 0 |
| `shover` | 8 | 12 | -4 |
| `careful` | 0 | 0 | 0 |

**BREACHED** — Preen healed more than the stance soaked:
- `shover`: healed 12 against 8 absorbed across the run

Fights where the heal was paid for out of an earlier fight's soaking. Expected —
this is the meter carrying between fights, not a leak:
- `shover` on `broken-bridge`: healed 4 against 0 absorbed in that fight
- `random-e` on `cb-06-bait-and-break`: healed 4 against 0 absorbed in that fight

**One hole remains, and it is not visible in these numbers.** A charge does not require
damage: an absorb that only moved the guard a tile earns a point while adding nothing to
the absorbed column, so three shoves that push a Wardbearer around without hurting him
would buy a Preen off zero soaking. No policy has managed it yet (D-084).
