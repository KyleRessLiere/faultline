## What is already correct in the patch

- `DeploySpot` board mark → `Grid.Spots` → `FightDefinition.DeploymentSpots`, with equality and hash.
- **`FightDefinition.Spots`** — the read-everything-through seam. Answers `DeploymentSpots`, or the
  **union of the two zones** on an unmigrated board, so the format change and the migration are
  separable. It is dead the day no board carries a zone.
- `Game.ApplyDeploy` and the legal-command list now ask *"is this a spot"*, never *"whose spot"* —
  that is §3's "not owned by either player", and it is the one piece of L1 that is done.
- `Threat.SafeDeploymentTiles` reads `Spots`, so the agency lint asks the board, not a side.
- `FightWriter` paints spots last, so migrated boards round-trip (this fixed ~11 failures).
- `CheckSpotFloor` + `FightIssueCode.SpotFloorUndeclared` — §3's floor, lint not error, silenced by a
  `design:` line mentioning the deployment. That is the thesis-vs-bug test the packet asked for.
- Ten act boards migrated; `AgencyTests.KnownUnsafe` stays **empty** and its test passes.
