FAULTLINE
=========

A two-player tactics game. You and one other person share a keyboard.


HOW TO PLAY
-----------

1. Unzip this folder somewhere you can find it again.
2. Double-click  Faultline
3. The game opens in your web browser.

That is all. Nothing to install, nothing to sign up for, no internet needed.


THE BLACK WINDOW
----------------

Double-clicking opens a black window with some text in it. That window IS the game
— it is doing the work while your browser draws it.

  * Leave it open while you play.
  * Closing it stops the game.
  * You can make it smaller, but do not close it until you are done.

If your browser did not open by itself, the black window has an address in it that
looks like  http://localhost:5299  — copy that into your browser.


IF SOMETHING GOES WRONG
-----------------------

"Windows protected your PC"
    Windows shows this for any program it has not seen many people run before. Click
    "More info", then "Run anyway". This is expected for a game somebody sent you
    rather than one you downloaded from a shop.

The browser opens but the page is blank
    Give it ten seconds on the first run — it is unpacking. If it is still blank,
    refresh the page once.

"The game files are missing"
    The folder was split up. Unzip the original zip again and keep everything
    together: the program needs the  wwwroot  folder sitting next to it.

Nothing happens at all
    Send whatever text is in the black window to whoever gave you this folder. That
    text is the whole diagnosis.


WHAT IS SAFE TO DELETE
----------------------

Nothing in this folder. It is all the game. To uninstall, delete the whole folder —
there is nothing anywhere else on your computer.
