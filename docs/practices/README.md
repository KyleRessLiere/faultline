# Practices

Load-on-demand detail for `CLAUDE.md`'s always-loaded contract. `CLAUDE.md` names these by trigger;
this index uses the same trigger phrases so the two agree.

| If the session… | Read |
|---|---|
| authors or edits `.fight` battles | [`BATTLE_AUTHORING.md`](BATTLE_AUTHORING.md) |
| fans out to subagents | [`SUBAGENTS.md`](SUBAGENTS.md) |
| writes a DECISIONS entry | [`DECISIONS_STYLE.md`](DECISIONS_STYLE.md) |
| adds/changes tests beyond the obvious | [`TESTING.md`](TESTING.md) |
| branches, releases, or touches CI | [`BRANCHING.md`](BRANCHING.md) |
| touches the renderer's structure | [`RENDERER.md`](RENDERER.md) |
| writes or reads a handoff | [`HANDOFFS.md`](HANDOFFS.md) |

These seven files hold material relocated from the pre-slim `CLAUDE.md`, moved verbatim apart from
each file's opening line naming when to read it. Nothing here is new practice — it is the same
practice, filed so a session that doesn't need it doesn't pay to read it.
